## 1. Opciones de Acceso Recomendadas

Para acceder a todo el material del diplomado, los estudiantes pueden elegir cualquiera de las siguientes vías:

1. **Portal Web Accesible (`index.html` / `Portal_Accesible.html`)**: *(Recomendado)*
   - Ábralo con doble clic en Microsoft Edge o Google Chrome.
   - Permite búsqueda instantánea con `Alt + 2`, anuncios en vivo de resultados y cambio de contraste con `Alt + 3`.
   - Enlace directo: [Abrir Portal Accesible HTML](index.html)

2. **Documento Maestro en Microsoft Word (`Guia_Accesible_Diplomado_VcM.docx`)**:
   - Ábralo en Microsoft Word.
   - Navegue por el panel de títulos (`Ctrl + B`) o la tecla `H` de su lector de pantalla.
   - Enlace directo: [Abrir Guía Accesible en Word](Guia_Accesible_Diplomado_VcM.docx)

3. **Explorador de Archivos de Windows**:
   - Todos los archivos y carpetas han sido renombrados con nombres autodescriptivos, fechas y números de sesión.
